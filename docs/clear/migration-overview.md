# Spring Boot + Thymeleaf 이관 개요

작성일: 2026-05-23

## 배경

기존 프로젝트는 PHP 기반 설문 접수/관리 사이트입니다. 앞으로 사이트 규모가 꾸준히 커질 예정이며, 설문 영역도 JSON 저장 방식에서 DB 저장 방식으로 전환할 계획입니다. 사용자 화면 역시 메인화면 추가, 설문화면 고도화, 뉴스탭 추가 등 확장이 예정되어 있습니다.

이 레포지토리는 기존 PHP 프로젝트를 직접 덮어쓰지 않고, Spring Boot + Thymeleaf 기반으로 새로 구축하기 위한 작업 공간입니다.

## 이관 판단

현재 상황에서는 단순 유지보수보다 Spring Boot 전환의 장기 이점이 큽니다. 특히 설문 DB화와 사용자 화면 확장이 동시에 예정되어 있으므로, PHP 내부에서 큰 구조 변경을 먼저 진행한 뒤 다시 이관하는 것은 중복 비용이 될 수 있습니다.

## 핵심 원칙

- 기존 PHP 프로젝트는 기준 구현으로 보존한다.
- 신규 기능 개발 전에 현재 핵심 기능을 Spring Boot에서 먼저 재현한다.
- 설문 저장 구조는 JSON이 아니라 DB 모델을 기준으로 재설계한다.
- 화면 용어, GNB/LNB, breadcrumb, 버튼 색상, 날짜 규칙은 기존 프로젝트 규칙을 유지한다.
- 런타임 데이터 파일인 `data/*.json`은 소스 관리 대상에서 제외한다.

## 1차 이관 범위

- 관리자 로그인/로그아웃
- 공통 관리자 레이아웃
- 설문 관리 목록
- 설문 등록/상세/수정
- 사용자 설문 목록/작성/완료
- 설문 이력 목록
- 설문 이력 상세
- 설문 이력 CSV 다운로드

## 2차 확장 후보

- 사용자 메인화면
- 설문 작성 화면 고도화
- 뉴스탭 및 AI 뉴스 관리
- 메뉴 관리 고도화
- 관리자 대시보드
- 관리자 접속/수정 이력

## 주의할 리스크

- 동적 설문 문항과 답변 구조의 DB 모델링
- checkbox/radio/select 옵션 저장 방식
- 기존 JSON 데이터 마이그레이션 여부
- Spring Security 기반 관리자 인증 재구현
- Thymeleaf layout fragment로 GNB/LNB/breadcrumb 안정화
- CSV 다운로드 한글 인코딩 및 날짜 포맷 검증
