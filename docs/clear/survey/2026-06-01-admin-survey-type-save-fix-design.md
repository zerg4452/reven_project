# 관리자 설문 등록 유형/저장 수정 설계

작성일: 2026-06-01

## 목표

관리자 설문 등록 화면에서 설문 문항 단위로 객관식/주관식 플래그를 선택할 수 있게 하고, 신규 등록 시에도 저장 흐름이 정상 동작하도록 수정한다.

## 가정

- 설문 유형은 설문 문항 단위의 분류로 본다.
- 기존 문항 `field_type`은 그대로 유지한다.
- 신규 설문은 `surveyUid`가 미리 생성되더라도 `surveySeq`가 없으면 아직 저장되지 않은 상태로 본다.

## 작업 범위

1. 설문 문항에 `surveyType` 값을 추가한다.
2. 관리자 설문 등록 화면에 문항별 설문 유형 선택 UI를 추가한다.
3. 신규/기존 설문 판별 기준을 `surveyUid`가 아니라 `surveySeq`로 바꾼다.
4. 저장 쿼리와 스키마를 문항 유형 컬럼과 맞춘다.
5. 회귀 테스트로 신규 등록과 수정 저장을 검증한다.

## 검증 기준

- 신규 설문 등록 화면에서 설문 유형을 선택할 수 있다.
- 신규 등록 화면이 등록 모드로 렌더링된다.
- 신규 저장 시 insert 흐름이 정상 동작한다.
- 기존 설문 수정 시 update 흐름이 정상 동작한다.
