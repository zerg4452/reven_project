# 관리자 설문 미리보기 설계

작성일: 2026-06-03

## 목표

관리자 설문 상세 화면에서 저장된 설문만 새 창으로 열어 사용자 설문 화면을 그대로 확인할 수 있게 한다. 미리보기는 실제 제출을 막고, 운영자는 문항 구성과 화면 레이아웃만 검토한다.

## 현재 상태

- 관리자 설문 상세 화면에는 목록, 저장, 삭제만 있다.
- 공개 설문 작성 화면 `client/survey/form.html`은 서버 렌더링이며 문항 fragment를 재사용한다.
- 설문 조회는 `SASurveyService.findSurvey()`로 처리된다.

## 선택한 방향

- 관리자 설문 상세에 `미리보기` 버튼을 추가한다.
- 버튼은 `target="_blank"`로 새 창이나 새 탭을 연다.
- 새 창 링크에는 `rel="noopener noreferrer"`를 붙인다. `target="_blank"`가 열린 창에서 원래 관리자 창을 참조하지 못하게 하기 위해서다.
- 진입 URL은 관리자 전용 `GET /admin/surveys/preview.do?surveyUid=...`로 둔다.
- 컨트롤러는 저장된 설문만 조회하고, 신규 작성 상태에서는 미리보기를 노출하지 않는다.
- 미리보기 화면은 공개 설문 UI를 그대로 쓰고, 제출은 막는다.
- 별도 저장, 임시 데이터 생성, 응답 전송은 하지 않는다.
- 잘못된 `surveyUid`나 삭제된 설문은 관리자 설문 목록으로 돌려보내고 `비정상적인 접근입니다.` 알림을 보여준다. 관리자 화면의 기존 흐름을 유지하고 500 오류 노출을 피하기 위해서다.

## 구현 변경

- `SAAdminSurveyController`에 preview GET을 추가한다.
- 관리자 설문 상세 템플릿에 미리보기 버튼을 추가한다.
- `client/survey/form.html`에 `previewMode` 분기를 추가한다.
- `previewMode`에서는 `<form>` 제출 경로를 끊는다.
  - `th:action`은 미리보기 모드에서 제거하거나 빈 값으로 둔다.
  - `onsubmit="return false"` 또는 동등한 방식으로 submit 이벤트를 막는다.
  - 제출 버튼은 렌더링하지 않는다.
  - 버튼만 숨기면 Enter 키나 스크립트로 실제 `/surveys/submit.do` 저장 요청이 갈 수 있으므로 form 제출 자체를 막아야 한다.
- `previewMode`에서는 제출자 정보와 문항 입력 요소를 모두 비활성화한다.
- `client/survey/field.html` fragment도 `previewMode`를 참조해 `textarea`, `select`, `radio`, `checkbox`, `date`, `number`, `email`, `text` 입력을 모두 `disabled` 처리한다. 실제 입력 요소 대부분이 fragment 안에 있으므로 form 템플릿만 수정하면 읽기 전용이 완성되지 않는다.
- 공용 헤더, 푸터, 문항 렌더링은 기존 사용자 화면과 동일하게 유지한다.
- 화면 상단에는 `관리자 미리보기 화면입니다. 응답은 저장되지 않습니다.` 안내를 표시한다. 공용 UI를 유지하되 제출 불가 상태를 운영자가 명확히 알 수 있게 하기 위해서다.

## 테스트 기준

- 저장된 설문 상세에서 미리보기 버튼이 보인다.
- 미리보기 버튼에 `target="_blank"`와 `rel="noopener noreferrer"`가 있다.
- 미리보기 URL이 200으로 렌더링된다.
- 미리보기 화면에 제출 버튼이 없다.
- 미리보기 화면의 form submit이 차단되어 실제 제출 저장 요청이 발생하지 않는다.
- 제출자 정보와 모든 문항 입력 필드가 비활성화된다.
- 신규 설문에는 미리보기 버튼이 없다.
- 잘못된 `surveyUid`는 관리자 설문 목록으로 이동하고 비정상 접근 알림을 보여준다.
- 기존 공개 설문 작성과 제출은 영향받지 않는다.

## 가정

- 새 창 동작은 `window.open` 대신 `target="_blank"` 링크로 처리한다.
- 읽기 전용 미리보기가 목적이므로 제출 성공이나 실패 분기는 추가하지 않는다. 대신 submit 자체가 발생하지 않게 한다.
- 대상은 저장된 설문만이다.
- 화면 외형은 공개 설문 UI 그대로 유지한다.
- 관리자 안내 문구는 미리보기 화면에만 표시한다.
