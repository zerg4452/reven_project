# 사용자 포토 게시판 설계

## 배경

관리자에는 포토 게시판 등록, 수정, 첨부 파일 관리가 구현되어 있다.
사용자 화면에는 현재 `게시판 > AI News`만 노출된다.
이번 작업은 사용자 GNB의 게시판 하위에 AI News와 포토 게시판을 함께 두고, 게시 상태의 포토 게시글을 카드형 목록과 상세 화면으로 제공하는 것이다.

## 범위

- 사용자 GNB의 게시판 드롭다운에 `AI News`와 `포토 게시판`을 노출한다.
- 사용자 포토 게시판 목록을 `/board/photo/list.do`로 제공한다.
- 사용자 포토 게시판 상세를 `/board/photo/detail.do?photoSeq=...`로 제공한다.
- 사용자 공개 파일 응답을 `/board/photo/file.do?photoFileSeq=...`로 제공한다.
- 목록은 한 화면 9개 기준으로 페이징한다.
- 목록 카드는 대표 썸네일, 제목, 등록일을 표시한다.
- 상세 화면은 제목, 등록일, 첨부 파일 그리드를 표시한다.
- 상세 첨부 클릭 시 딤드 레이어 팝업으로 이미지 확대 또는 동영상 재생을 제공한다.
- 제목 검색과 `이미지 포함`, `동영상 포함` 체크박스 검색을 제공한다.

## 제외 범위

- 관리자 업로드 화면의 신규 입력 항목 추가는 하지 않는다.
- 확장자 컬럼이나 파일 종류 컬럼을 새로 추가하지 않는다.
- 게시판 허브 페이지는 만들지 않는다.
- 동영상 썸네일 이미지 생성은 하지 않는다.

## 내비게이션

현재 사용자 GNB는 `게시판` 상위 메뉴 아래 `AI News`만 있다.
이를 `게시판 > AI News / 포토 게시판`으로 확장한다.
상위 `게시판` 링크는 기존 동작과 호환되도록 AI News 목록을 유지한다.
포토 게시판 링크는 `/board/photo/list.do`를 사용한다.

## 목록 화면

목록은 게시 중이고 삭제되지 않은 포토 게시글만 보여준다.
카드는 9개씩 표시하며 데스크톱에서는 3열 그리드, 좁은 화면에서는 1열 또는 2열로 줄인다.
카드에는 대표 썸네일, 제목, 등록일을 표시한다.
카드 전체를 클릭하면 상세 화면으로 이동한다.

대표 썸네일은 해당 게시글의 삭제되지 않은 첨부 중 `sort_ord asc, photo_file_seq asc` 기준 첫 번째 파일을 사용한다.
대표 파일이 이미지면 `img`로 표시한다.
대표 파일이 동영상이면 `video muted preload="metadata"`로 미리보기를 표시한다.

## 검색

검색 조건은 제목 키워드와 파일 유형 체크박스 2개다.
제목 검색은 포토 게시글 제목에 대해 부분 일치로 처리한다.
`이미지 포함`은 삭제되지 않은 첨부 중 `content_type like 'image/%'` 파일이 있는 게시글을 찾는다.
`동영상 포함`은 삭제되지 않은 첨부 중 `content_type like 'video/%'` 파일이 있는 게시글을 찾는다.
두 체크박스를 모두 선택하면 OR 조건으로 처리한다.
아무 체크박스도 선택하지 않으면 파일 유형으로 제한하지 않는다.

파일 유형 판별은 기존 `bd_photo_board_file_dtl.content_type`을 사용한다.
업로드 시 이미 확장자와 MIME 타입 검증이 있으므로 별도 확장자 컬럼은 만들지 않는다.

## 상세 화면

상세 화면은 게시 중이고 삭제되지 않은 글만 렌더링한다.
정상 게시글이면 제목, 등록일, 첨부 파일 그리드를 보여준다.
첨부 파일 카드는 이미지 또는 동영상 미리보기와 파일명을 표시한다.
첨부 파일을 클릭하면 딤드 배경의 레이어 팝업을 띄운다.
이미지는 확대 이미지로 보여준다.
동영상은 같은 팝업 안에서 `video controls`로 재생한다.

`photoSeq`가 없거나, 존재하지 않거나, 삭제되었거나, 비게시 상태인 상세 접근은 정상 화면을 보여주지 않는다.
대신 `비정상적인 접근입니다.` 알럿을 띄우고 `/board/photo/list.do`로 이동시킨다.

## 공개 파일 접근

사용자 화면은 관리자 파일 URL을 사용하지 않고 공개 파일 URL을 사용한다.
`/board/photo/file.do?photoFileSeq=...`는 파일이 게시 중이고 삭제되지 않은 포토 게시글에 속할 때만 inline 응답한다.
파일이 없거나, 삭제된 파일이거나, 비게시/삭제 게시글의 파일이면 404로 응답한다.
이미지나 동영상 태그가 호출하는 리소스 요청에서는 알럿을 띄울 수 없으므로 리소스 접근 차단은 404로 처리한다.

## 구현 단위

- `BDPhotoBoardService`에 공개 목록 검색, 공개 상세 조회, 공개 파일 조회 메서드를 추가한다.
- `BDPhotoBoardMapper`와 XML에 공개 목록, 공개 목록 개수, 공개 상세, 공개 상세 파일, 공개 파일 조회 쿼리를 추가한다.
- 공개 목록 응답 DTO에는 대표 파일 일련번호, 대표 파일 MIME 타입, 대표 파일 URL, 이미지 포함 여부, 동영상 포함 여부를 포함한다.
- 공개 검색 요청 DTO에는 제목 키워드, 이미지 포함 여부, 동영상 포함 여부, 페이지 정보를 포함한다.
- 사용자 컨트롤러는 `BDPhotoBoardPublicController`를 새로 둔다.
- 사용자 템플릿은 `client/photo/list.html`, `client/photo/detail.html`을 새로 둔다.
- CSS는 기존 public 화면 톤을 유지하면서 포토 카드 그리드, 검색 체크박스, 상세 첨부 그리드, 미디어 모달 스타일만 추가한다.
- JS는 관리자 이미지 모달 패턴을 참고하되 사용자 상세에서 이미지와 동영상을 모두 처리하도록 별도 공개 스크립트를 둔다.

## 오류 처리

목록은 검색 결과가 없으면 기존 사용자 화면 문구와 맞춰 빈 상태를 표시한다.
상세 비정상 접근은 알럿 후 목록으로 이동한다.
공개 파일 비정상 접근은 404로 응답한다.
서비스 계층은 공개 조회에서 비게시/삭제 데이터를 반환하지 않는다.

## 검증 기준

- 사용자 GNB의 게시판 드롭다운에 AI News와 포토 게시판이 함께 보인다.
- `/board/photo/list.do`에서 게시 상태 포토 게시글이 9개씩 카드로 보인다.
- 제목 검색이 동작한다.
- 이미지 포함 체크박스가 이미지 첨부 게시글을 찾는다.
- 동영상 포함 체크박스가 동영상 첨부 게시글을 찾는다.
- 이미지 포함과 동영상 포함을 모두 체크하면 OR 조건으로 찾는다.
- 상세 화면에서 이미지와 동영상 첨부를 레이어 팝업으로 볼 수 있다.
- 비게시 또는 삭제 게시글 상세 접근 시 `비정상적인 접근입니다.` 알럿 후 목록으로 이동한다.
- 비게시 또는 삭제 게시글의 파일 직접 접근은 404로 응답한다.
- 관련 서비스 테스트와 컨트롤러 테스트가 통과한다.
