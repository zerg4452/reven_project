# 사용자 메인/뉴스/설문 화면 설계

## 목표

`/`, `/main.do`, `/index.do`로 접근하면 사용자 메인 화면을 표시한다. 사용자 화면에서는 관리자 이동 버튼을 노출하지 않고, GNB에 `뉴스`와 `설문` 메뉴를 두며 마우스 오버 시 하위 메뉴를 보여준다.

## 선택한 방향

B안인 사용자용 강조형을 적용한다. 상단에는 16:9 비율의 큰 이미지 영역을 두고, 그 아래에는 `진행중인 설문`을 좌측에 더 강조된 카드로, `뉴스 신규 글`을 우측에 아코디언 성격이 느껴지는 카드로 배치한다. 각 영역은 최대 3건만 노출하고, 우측 상단 `더보기`는 해당 목록으로 이동한다.

## 화면 구성

- 사용자 공통 GNB: 브랜드, `뉴스 > AI`, `설문 > 진행중인 설문` 메뉴를 표시한다.
- 메인 화면: 상단 히어로 이미지, 진행중인 설문 3건, 게시 상태 뉴스 3건, 하단 미정 영역 이미지를 표시한다.
- AI 뉴스 화면: 관리자에서 등록한 뉴스 중 게시 상태인 글만 FAQ/아코디언 형태로 출력한다. 검색은 제목과 내용 전체를 대상으로 한다.
- 설문 화면: 현재 진행중인 설문을 카드 형태로 우선 노출한다. 마감/미사용 설문은 딤드 처리하고 `마감` 및 `참여 불가` 표시를 명확히 한다.

## 데이터와 상태 기준

- AI 뉴스 공개 조건은 기존 관리자 상태 코드 중 `Y`를 게시 상태로 본다.
- 설문은 기존 `use_yn = 'Y'`를 진행중으로 본다. 공개 설문 목록은 삭제되지 않은 설문을 모두 가져와 `use_yn`에 따라 진행/마감 UI를 구분한다.
- 날짜 표시는 기존 프로젝트 규칙대로 `yyyy-mm-dd`를 유지한다.

## 구현 경계

- 새 DB 테이블은 추가하지 않는다.
- 기존 관리자 화면의 GNB에는 `사용자 화면` 링크를 유지하지만, 사용자 화면용 GNB에는 관리자 이동 링크를 만들지 않는다.
- 하단 IT 이미지는 생성형 이미지 파일을 정적 리소스로 저장하고 템플릿에서 참조한다.

## 검증

- 컨트롤러 테스트로 `/`, `/main.do`, `/index.do`, `/news/ai/list.do`, `/surveys/list.do`의 주요 모델과 템플릿을 검증한다.
- 빌드 또는 테스트 명령을 실행해 Java/Thymeleaf 변경이 컴파일 가능한지 확인한다.
